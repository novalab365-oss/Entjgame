# 온 세상이 ENTJ라면? · 프로토타입 0.2

기존 ENTJ 액션 게임과 무관한 독립 프로젝트. 외부 아트 에셋 없음.

실행: Node.js 24 이상에서 `npm ci` 후 `npm start`, 브라우저에서 `http://localhost:3000` 접속.
빌드 결과는 `dist/`에 포함됨. 서버 판정·저장을 사용하므로 index.html만 열거나 정적 호스팅에 올리면 작동하지 않음.
다시 빌드: `npm run build`. 검사: `npm test`.

- client/: 입장·UI·3D 도형·카메라·네트워크 표시
- server/: 세션·실시간 방·자리·알바 판정·수익·랭킹
- shared/config.mjs: 수치·문구·가게·충돌 위치·문제
- shared/navigation.mjs: 이동 경로
- tests/: 로직과 실제 HTTP/WebSocket 전송 검사
- data/village.sqlite: 실행 시 생성되는 기록 DB. 서버를 옮길 때 유지해야 함.

완료: 도형 마을, 이동/충돌, 알바 2종, 자리 점유, 서버 보상, 게스트 기록, 방 자동 배정, 말풍선·몸짓, 상대 수익, KST 일일 통합 랭킹, 재접속, 중복 탭 차단, 빌드.
검증: 핵심 로직 검사와 로컬 WebSocket 클라이언트 2개 통신, 브라우저 입장·마진 알바·수익/랭킹 반영. 가상 테스트 클라이언트는 실제 이용자 접속 검증이 아님.
미검증: 외부 여러 기기 접속, 실제 모바일 10명 성능, WebGL 렌더링. 내부 확인 브라우저는 WebGL이 비활성화되어 SVG 호환 렌더링으로 확인.
배포: 수행하지 않음. 비용·외부 계정 추가 없음. 운영 시 Node 장기 실행/WebSocket과 영구 디스크가 필요. 현재 단일 프로세스가 여러 방을 관리하며 다중 서버 확장은 범위 밖.

이어 할 일: 실제 기기 시야·조작 확인, 외부 실행 환경 결정 후 멀티플레이 연결 검증. 이미 완료한 소스/검사를 유지하여 해당 부분만 수정.

## v02 · 아이패드/모바일 우선 수정
- 상단 요약, 왼쪽 하단 교류, 오른쪽 하단 랭킹. 알바 패널 높이에 따라 버튼/목록 자동 배치.
- VisualViewport 높이·위치, 안전 영역 대응. 입장 중/시간 초과/재시도 및 중복 요청 차단.
- 터치 좌우 드래그, PC 우클릭 드래그 회전. 탭과 드래그/길게 누르기/멀티터치 구분. 상하 회전/줌/점프 없음.
- 캐릭터 수익 패널 반복 선택 오류 수정. 카메라 앞 가게 벽은 가림 방지 처리.
- 검증: 브라우저의 820×1180, 390×740, 390×560 프레임에서 패널 잘림/겹침 확인. 수익 패널 반복 열기 확인. 입력 분류 검사 3개 및 두 WebSocket 클라이언트 간 상대 수익 조회 통과.
- 구분: 세로 레이아웃=명세/구현/해당 크기 실행 확인. 회전=명세/구현/입력 로직 검사, 실제 터치 회전 미검증. 상대 수익=명세/구현/창 실행 및 두 클라이언트 조회 확인, 실제 다기기 미검증.
- 실제 iPad Safari·인스타 내부 브라우저, 키보드/브라우저 바 변화, WebGL, 10명 성능은 실기 미검증. 배포/외부 접속 URL 없음.

## 저장소/배포 연결 준비
- Dockerfile: Node 24 서버와 웹 빌드를 하나의 컨테이너로 실행.
- compose.yaml: SQLite 기록 영구 볼륨. 외부 공개는 별도 HTTPS 프록시/호스팅에서 연결.
- .github/workflows/build.yml: 요청할 때만 수동 실행하는 검사/빌드. 커밋마다 자동 빌드하지 않음.
- GitHub 저장소: https://github.com/novalab365-oss/Entjgame
- 실행 호스팅 미연결. 외부 플레이 URL 없음. 서버와 영구 저장소의 비용 조건 확인이 필요함.
- 다음 단계: WebSocket·영구 디스크 지원 서버 연결 → 배포 → 아이패드 링크 검증. 유료 가입은 별도 확인.
